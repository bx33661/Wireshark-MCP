# Claude Repository Guide

For packet capture and traffic-analysis work in this repository, load the project skill from `skills/wireshark-traffic-analysis/SKILL.md`.

Use it for:

- `pcap` and `pcapng` analysis
- security hunting and incident response
- network troubleshooting

Prefer the skill playbooks, evidence rubric, and report template over ad hoc analysis. Use `wireshark_aggregate` for capture-wide statistics and packet-level tools to verify important groups.
